# Icon

A Material Symbols Rounded glyph by name; inherits colour from its parent.

## Props
- `name` — any [Material Symbols](https://fonts.google.com/icons) name, Rounded style.
- `size` — px (default 20). `label` — set for meaningful standalone icons; otherwise it is hidden from screen readers.

## Do / don't
- Icons inherit `color`; tint with `ink-muted` by default, `primary` for active.
- Don't use emoji in place of icons.
