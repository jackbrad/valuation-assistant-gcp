# Badge

Short status or category label; tones carry a glyph so status never relies on colour.

## Props
- `tone`: `neutral` (default) · `brand` · `success` · `warning` · `danger` · `new` (marigold fill, once per screen).
- `icon` — a Material Symbols name; success/warning/danger default to check/warning/error. `icon={false}` removes it.
- `children` — one or two words, sentence case.
